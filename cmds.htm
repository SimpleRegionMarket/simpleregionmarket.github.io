/srm Get Informations about SimpleRegionMarket /srm help Get help about the Commands /srm reload Reloads the config-file /srm limits <limit> List of all limits <limit> - name of limit to show (/srm limits signs.let.global) /srm statistics/stats <player> [type] Show statistics about SRM [type] -  Type of statistics global, usersell or userbuy /srm clearstatistics Clear statistics file /srm moneys <player> <page> Show statistics about Players Moneys <page> - Number of page /srm list <page> <market type> <filters> List of all buyable Regions <page> - Number of page <marker type> - Type of marker (sell, rent, let, bid) <filters> - Use to filter results (filters: radius, minradius, minprice, maxprice, minrenttime, maxrenttime)  example: /srm list 2 minprice:5.8 maxprice:15 radius:23 /srm clear/untake [region name] <world> Remove all members from region [region name] – name of region to clear <world> - name of world where is region /srm clearall Remove all owners from every Region /srm remove [region_name] <world> Remove Region from Market-List [region name] – Name of Region to remove <world> - Name of World where is Region /srm removeall remove all Region from Market-List /srm clearlimits  Clear all Limits
