Permissions

By default, players are able to use and create every sign type, use the teleport features, check limits, see the list of regions, and add and remove members. Every feature except the admin commands are enabled by default. There are 2 ways to disable permissions if you do not want players to have all access:

  1. Extract the contents of SimpleRegionMarket.jar and edit the default values for each perm node found in plugin.yml and repack the jar
  2. Use your permission manager of choice to negate the permissions you do not want users to have.
    • Each permission plugin is different and we can not provide tutorials on each of them.
    • Please consult your permission plugin documentation or developers on how to do this.

Permission Nodes

permissions:
    simpleregionmarket.signs.*:
